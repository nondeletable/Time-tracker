# Этап 1 — i18n (ru + en) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ввести инфраструктуру локализации (ru + en), вынести все существующие UI-строки в словари и добавить вкладку настроек «Общие» с переключателем языка.

**Architecture:** Чистый модуль i18n (детект языка + перевод по ключу) в UMD-стиле — работает и как `require` в node:test, и как глобал в браузере (рендерер — плоский скрипт без сборщика). Словари `ru`/`en` — плоские объекты `key → строка` плюс массивы названий месяцев/дней недели для календаря. HTML размечается атрибутами `data-i18n` / `data-i18n-title` / `data-i18n-placeholder`; при загрузке и при смене языка `app.js` проставляет переводы. Язык хранится в `settings.lang`, дефолт — по локали ОС.

**Tech Stack:** Electron, vanilla JS (без сборщика), `node:test` для чистой логики, ручная проверка UI через `npm run dev`.

## Global Constraints

- Рендерер грузится одним `<script src="js/app.js">` без модульной системы — общий код подключать через UMD-обёртку (`module.exports` в node, `window.*` в браузере).
- Все пользовательские строки идут через словарь; хардкод текста в разметке/JS не допускается (кроме брендовых: «Time Tracker»).
- Оба словаря (`ru`, `en`) обязаны иметь идентичный набор ключей — это проверяется тестом.
- Дефолтный язык: русская локаль ОС → `ru`, иначе `en`.
- Стиль коммитов проекта: `feat:` / `test:` / `refactor:` и т.п.

Create `src/renderer/js/i18n/i18n.js`:
```js
// Чистая логика i18n — без DOM. UMD: работает и в node (require), и в браузере (window.I18N).
(function (root, factory) {
  const api = factory()
  if (typeof module !== 'undefined' && module.exports) module.exports = api
  else root.I18N = api
})(typeof self !== 'undefined' ? self : this, function () {
  function detectLang(locale) {
    return String(locale || '').toLowerCase().startsWith('ru') ? 'ru' : 'en'
  }

  function translate(dict, lang, key) {
    const table = dict[lang] || {}
    if (key in table) return table[key]
    const en = dict.en || {}
    if (key in en) return en[key]
    return key
  }

  function keySets(dict) {
    const out = {}
    for (const lang of Object.keys(dict)) {
      out[lang] = Object.keys(dict[lang])
        .filter(k => k !== 'months' && k !== 'weekdays')
        .sort()
    }
    return out
  }

  return { detectLang, translate, keySets }
})
```

```js
let currentLang = 'ru'

function t(key) {
  return window.I18N.translate(window.DICT, currentLang, key)
}

function applyI18n() {
  document.documentElement.lang = currentLang
  document.querySelectorAll('[data-i18n]').forEach(el => {
    el.textContent = t(el.getAttribute('data-i18n'))
  })
  document.querySelectorAll('[data-i18n-title]').forEach(el => {
    el.setAttribute('title', t(el.getAttribute('data-i18n-title')))
  })
  document.querySelectorAll('[data-i18n-placeholder]').forEach(el => {
    el.setAttribute('placeholder', t(el.getAttribute('data-i18n-placeholder')))
  })
}
```
