# Кастомный titlebar + ресайз окна — дизайн

Дата: 2026-09-03
Статус: согласовано, готово к плану

## Цель

Заменить нативный заголовок Electron на кастомный титлбар в стиле приложения и
включить ресайз окна (сейчас окно фиксировано 700×600, `resizable: false`).
Блок кнопок окна (свернуть/развернуть/закрыть) — собственный, перекрашенный под
тему.

## Продуктовые решения (согласовано)

- **Лейаут:** одна строка (merge с текущей шапкой). Слева бургер, по центру
  иконка + название, справа sync-индикатор + кнопка `Sync` + кнопки окна.
- **Углы/рамка:** нативные скруглённые углы Windows 11 (`frame: false` +
  `resizable: true`, БЕЗ `transparent`) — остаются нативная тень и края ресайза.
- **Память окна:** размер и позиция сохраняются между запусками.
- **Иконки:** пользователь подготовила PNG в `assets/` (`minus-sign.png`,
  `full-screen.png`, `close.png`) — перерисовать в SVG и перекрасить под тему
  (`#9090b0`, как `menu.svg`).

## 1. Окно (`src/main/index.js`)

- `BrowserWindow`: `frame: false`, `resizable: true`, `minWidth: 560`,
  `minHeight: 500` (значения проверить на реальном layout при сборке, подстроить
  при необходимости). Без `transparent`.
- **Сохранение bounds:** ключ `window_bounds` в `settings` (JSON:
  `{ width, height, x, y, maximized }`). Пишется при закрытии окна
  (`win.on('close')` → `win.getBounds()` + `win.isMaximized()`; если maximized —
  сохраняем `getNormalBounds()` как размер и флаг `maximized: true`).
- **Восстановление при старте:** читаем `window_bounds`; прогоняем через чистую
  `clampBoundsToScreen(bounds, displays)` — если окно не попадает ни на один
  дисплей, откатываемся к дефолтным центрированным 700×600. Если `maximized` —
  создаём с сохранённым размером и вызываем `win.maximize()`.
- Дефолт (нет ключа / невалиден): 700×600.

## 2. Титлбар (бывший `.app-header`, одна строка)

Три зоны; вся строка — drag-регион (`-webkit-app-region: drag`), все
интерактивные элементы — `no-drag`:

- **Слева:** бургер-кнопка + dropdown (как сейчас; `no-drag`).
- **Центр:** иконка приложения (`time-management.png`, ~16px) + текст
  «Time Tracker». Абсолютно по центру строки, часть drag-региона.
- **Справа:** `sync-dot` + кнопка `Sync` (как сейчас, `no-drag`) → блок кнопок
  окна: свернуть / развернуть-восстановить / закрыть (`no-drag`).
- Двойной клик по drag-региону → maximize/restore (нативное поведение Windows,
  отдельно кодить не нужно).
- Высота титлбара — как у текущей шапки (~40px), окно по высоте не растёт.

## 3. Кнопки окна (SVG)

- Три файла в `assets/icons/`: `win-min.svg`, `win-max.svg`, `win-close.svg`,
  цвет `#9090b0` (перерисованные глифы из PNG: скруглённый минус, «уголки»,
  крест). Стиль — как `menu.svg`/`user.svg` (тонкие штрихи под тёмную тему).
- В maximized-состоянии иконка «развернуть» свапается на «восстановить» (уголки
  внутрь). Триггер — события из main (`win:maximized` / `win:unmaximized`).
- Размеры кнопок: ширина шире обычной (как в Windows-заголовке), высота = высоте
  титлбара. Ховер: `close` → красный (`#f87171`) фон/иконка; `min`/`max` →
  подсветка светлее (напр. `#1a1a24`), иконка светлее.

## 4. IPC (`src/main/index.js` + `src/preload/index.js`)

- `win:minimize` → `win.minimize()`.
- `win:maximize-toggle` → `win.isMaximized() ? win.unmaximize() : win.maximize()`.
- `win:close` → `win.close()`.
- События в renderer: `win:maximized` / `win:unmaximized`
  (`win.on('maximize' | 'unmaximize')`) — для свапа иконки max↔restore.
- preload: `winMinimize()`, `winMaximizeToggle()`, `winClose()`,
  `onWinMaximized(cb)`, `onWinUnmaximized(cb)`.

## 5. Ресайз контента

- Layout уже флексовый: `.main-wrapper` — колонка; `.layout` — `flex:1` +
  `min-height:0`; сайдбар 230px фикс, основная зона `flex:1`; списки категорий/
  статистики скроллятся. При включении ресайза проверить:
  - таймер-зона (круглая кнопка) не переполняет основную зону на min-высоте;
  - шкала лимита и per-category бары корректно тянутся по ширине;
  - при большой ширине контент не «разъезжается» некрасиво (при необходимости —
    `max-width` на основную зону или центрирование).
- Правки только точечные, без переписывания layout.

## 6. Тесты

- `node:test` для чистой `clampBoundsToScreen(bounds, displays)`: окно внутри
  экрана → без изменений; окно вне всех экранов → дефолт; частичное пересечение —
  по выбранному правилу (достаточно, чтобы заголовок был доступен).
- Титлбар (drag, кнопки, свап иконки, двойной клик), ресайз, восстановление
  размера между запусками — ручная проверка `npm run dev`.

## 7. Явно НЕ входит (YAGNI / отложено)

- Светлая тема и вынос цветов в CSS-переменные (банк идей).
- Кастомный радиус углов / собственная рамка (выбраны нативные углы Win11).
- Кросс-платформенные раскладки кнопок (macOS слева и т.п.) — приложение под
  Windows.
