# UI-прототип

tt-prototype.html - прототип интерфейса, предложение по внешнему виду прилы.

Логика внутри - заглушка. Данные синтетические и зашиты в разметку, таймер считает от произвольного значения и никуда не пишет, категории не редактируются, синхронизации и i18n нет.
Щёлкай переключатели сверху - переход между режимами приложения, четыре темы, эффекты частиц и блобов.

Focus mode - окно с единственным героем экрана - кольцом таймера, ничего постороннего, календарь и настройки туда не вынесены намеренно. Зато есть спецэффекты для медитативности.
Dashboard - рельс слева и бенто-сетка: общий лимит с вкладом обоих участников, распределение по категориям, столбцы по дням, таблица категорий, календарь и настройки как отдельные виды. Все данные вынесены сюда.

Переключение - кнопка **T** в углу окна или **Ctrl+M**. Переход идёт круговой волной от этой кнопки: каждый элемент появляется с задержкой, равной его расстоянию до неё, поэтому интерфейс рождается под фронтом волны. В настройках есть скорость перехода и вариант Fade — без волны, обычным проявлением.

**Четыре темы.** Emerald и Indigo, каждая в тёмной и светлой. Тема задаёт всю палитру целиком, не только акцент. Все цвета вынесены в CSS-переменные - перенос в приложение осуществляется подстановкой токенов.

**Фоновые эффекты в Focus** (canvas): пыль, эмиссия от кольца с воронкой, вращающиеся частицы, сетка точек с полем притяжения, полярное сияние и световые засветы. Палитру берут из активного акцента. Выключаются полностью; при `prefers-reduced-motion` не запускаются вовсе.
