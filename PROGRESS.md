## Шкалы прогресса
Обновлено: 2026-06-23

- IPC-хендлер `db:get-monthly-stats`: суммируем по пользователю за расчётный период

- Per-category шкалы: относительные (лидер = 100%), формат Xh Ym Zs, скролл при переполнении
- Обе шкалы обновляются после каждого сохранения сессии
- Кастомный скроллбар: без стрелок, закруглённый, цвета приложения
- bat-файл `launch.bat` в корне проекта

- Шкалы категорий — относительные (лидер = 100%). Переход на 160ч — одна строка, если понадобится
- Период — явные даты, не "28-е число", чтобы форс-мажор решался правкой двух полей в настройках

## LAN-синхронизация
Обновлено: 2026-06-25

### ✅ Сделано
- Каждая машина поднимает WebSocket-сервер на порту 43210
- UDP-broadcast на порту 43211 каждые 30 с — авто-обнаружение второго пользователя без ручного ввода IP
- При обнаружении peer — немедленный обмен данными + повтор каждые 5 минут
- При обрыве соединения — автоматический реконнект через 30 с
- Синхронизируется: суточные агрегаты (user + day + total_seconds) + аватар пользователя
- Данные второго пользователя хранятся в таблице `peer_data` (SQLite) — переживают перезапуск
- `db:get-shared-total` и `db:get-calendar-month` учитывают данные из обеих таблиц
- Аватар второго пользователя пишется в `settings` и сразу отображается в календаре
- Серый/зелёный индикатор в шапке приложения показывает статус соединения
- Зелёный индикатор зажигается и при входящем соединении (не только при исходящем)
- WS-сервер отправляет свои данные обратно при получении данных от peer (двусторонний обмен)
- Кнопка ⟳ в шапке для ручной принудительной синхронизации
- Приложение полностью работает в офлайн-режиме
- Синхронизация протестирована между двумя машинами — работает в обе стороны

### 💬 Решения
- Синхронизируем суточные агрегаты, не сессии — минимум данных, достаточно для лимита и календаря
- Оба приложения одновременно сервер и клиент — нет единой точки отказа
- `INSTANCE_ID` (random) фильтрует собственные UDP-broadcast
- Для работы синка оба пользователя должны разрешить исходящие соединения в Malwarebytes Windows Firewall Control для своего процесса (`electron.exe` / `time-tracker.exe`)
